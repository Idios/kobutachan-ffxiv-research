## 4. 表記の判断（どこかを直すときはここも直す）

- **中黒**: 原稿の `・` はすべて `·`（U+00B7）に置き換えた。訳文に `・` は 1 つも無い（キーは原稿どおりなので `{0}・{1}` などのキーには殘る）。
- **単位**: 数に詰める（コードが後ろに付ける）。第 1 回査読で `秒間→秒`、`分→分钟`、`秒毎→秒` に変えた（tick は `每{1}：{0}`）。`秒前 / 秒后` はそのまま（雛形側の「前／後」を落として二重を消した）。`/分` は中国語でも同じ字面。
- **助数詞（原稿の en/de/fr が `∅` の行）**: 中国語は数に助数詞を付けるので空にせず、`か所→处`, `体→个`, `個→个`, `基→座`, `回→次` を置いた。英語・ドイツ語・フランス語の `∅` は「その言語では何も出さない」の意味だが、中国語で数を裸で出すと不自然になるための相違。コードは中国語で数と単位の間を空けない（生成物で確認済み）。
- **Triumph の語彙（第 1 回査読で確定）**: `戦略目標地→战略目标点`、`戦略サークル→占领区域`、`制圧→控制`、`雪→小雪`、`雪像→雪人`。`確定` は状態名ではないので、文では `占领完成` / `已占领` と書く。根拠は中国版公式の沃刻其特（演习战）ページ。
- **`撃破` と `被撃破`**: 中国版は対人を「击倒」、受け身を「被击倒」と書く（沃刻其特のページ）。台帳の `撃破`（en: KO）は対人なので `击倒`、`被撃破` は `被击倒` で確定。ドローンの「截击」は別の語。
- **`リミットゲージ`**: 用語表は公式の `极限技积蓄条`（PvP 共通ルール）、画面の見出し（`ui.md` の `リミットゲージ {0}`）は沃刻其特のページの短い呼び方 `极限槽{0}`。極限技そのものは `极限技`。英語も terms=Limit gauge / ui=Limit gauge {0} で役割が分かれている。
- **見出しの長さ**: 表の見出し・行ラベルは 1280×720 に収めるため、`与ダメ→给予伤害`（公式の表見出し）, `被ダメ→受到伤害`, `ジョブ→特职`, `出典→出处`, `一覧→列表` など 2〜4 字に寄せた。長い注記（`このサイトの値の出典…`, `与ダメ・被ダメは…`）は英語版と同じ段落扱いで、字数制限はかけていない。
- **`text.md` の Triumph 系（`TRI-*`）**: `占领区域`・`控制`・`占领完成` を含む。語を差し替えるときは `TRI-*` の行も一緒に直す。`SEC-*` / `NAA-*` / `SEI-*` / `SHA-*` は中国版公式の各ページ（阵地战・争夺战・碎冰战・竞争战）に沿って訳した。

## 5. コード側で直した点

`frontline/tools/i18n.py` の `U()` は「訳の 1 文字目が英字なら数との間に空白を入れる」判定に `v[:1].isalpha()` を使っていた。Python の `isalpha()` は漢字にも `True` を返す（`'秒'.isalpha() is True`）ため、この JSON をそのまま流すと画面では `15 秒` のように空白が入る。

**修正済み（2026-11-17）**: 空白を入れるのはラテン文字の言語（en/de/fr）だけにし、中国語・韓国語の単位は数に付けるように変えた。`C()` が返した訳済みの語を `U()` が二重に訳していた問題（`合計の単位: 戦術値`）も、表にある語だけ訳すようにして直した。
