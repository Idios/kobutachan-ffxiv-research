## 1. プロジェクト定義

**目的**: MMORPG『FINAL FANTASY XIV』（以下 FFXIV）の開発・運営・事業構造を分析し、**3年先（暦年2029年前後／FY2030.3期）の事業規模とプレイヤー数**を、根拠のあるレンジとして推定する。

**対象外**: スクウェア・エニックス・ホールディングス（9684）の株価・バリュエーション判断。9684のIRは**FFXIV事業の実態を推定するためのデータソース**として使う。

**分析の主軸となる因果連鎖**:

```
コンテンツ供給（拡張・パッチの量と質）
  → プレイヤー行動（新規流入 / 継続 / 復帰 / 離脱）
    → 活動アカウント数（国勢調査ベース）
      → 課金サブスク数（推定）
        → ARPU × 課金数 = FFXIV売上（グローバル直営）＋ ライセンス収益
          → 事業規模（売上・利益）
            → 開発投資余力 → 次のコンテンツ供給（フィードバック）
```

このループのどこが強く、どこが壊れかけているかを特定することが分析の本体。

### 2-1. K1の正確な定義と、その落とし穴（最重要）

Lucky Bancho国勢調査の「アクティブ」は素朴な「ログインしたキャラ」ではない。少なくとも以下の条件が入る:

- **プロフィール・ミニオン・マウントを全体公開しているキャラのみ**が母集団 → 非公開設定者は構造的に除外（オプトアウトバイアス）
- 前回調査比でレベル／経験値等に**変動があること** → 課金中でも数値が動かない層（ハウジング維持のみ、高難易度練習のみ等）は未カウント
- **フリートライアル到達範囲のキャラを除外**する処理が入っている
- ジャンピングポーション使用キャラの除外処理

**構造断絶**: フリートライアルの上限は Lv35 → 60 → 70 → 80 と段階的に拡大しており、**パッチ7.5でも漆黒Lv80まで拡大され、それに伴い集計基準が修正されている**。つまり予測の起点となる直近データに定義変更由来のレベルシフトが混入している。

→ **これを未処理のまま「7.x期の減少」を論じるとRQ1の判定そのものが壊れる。** Phase 2の最重要課題として、トライアル範囲拡大の各時点で系列に段差補正（または区間分割）を行い、補正前後の両系列を保持する。

### 2-2. K1→K3変換の双方向漏れ

| 漏れの方向 | 内容 | 対処 |
|-----------|------|------|
| 課金しているがK1に入らない | 経験値・レベルが動かない課金者（ハウジング維持、絶練習等） | 変換係数に織り込み、拡張後期ほど比率が上がる仮説を検証 |
| 課金していないがK1に入る | **フリーログインキャンペーン**中の復帰者。キャンペーンはパッチ直後に打たれるため調査タイミングと系統的に相関する | キャンペーン実施カレンダーをPhase 1/2の必須データとし、時変要因として明示的に補正 |

この2つを無視すると、K3推定は**方向性のあるバイアス**（ランダム誤差ではない）を持つ。

### 2-3. K1の観測範囲 ≠ K4の収益範囲

国勢調査はグローバル版（JP/NA/EU/OC）のみを見ている。中国版・韓国版のキャラはLodestoneに存在しない。一方でIRのMMO売上にはライセンス収益が入りうる。

→ K4を **K4a（グローバル直営）と K4b（ライセンス）に最初から分解**する。K1→K2→K3→K4a のみを変換連鎖でつなぎ、K4bは別ロジック（契約形態・現地サービス状況）で扱う。

**【Phase 1で判明した構造変更】** ライセンス収益が**MMOサブセグメントに含まれている証拠がない**（決算説明会資料・有報・短信のいずれにも中国版・繁体字版・FFXIVモバイルへの言及がなく、収益分解注記にライセンス／ロイヤリティの区分自体が存在しない）。構造上は「ライツ・プロパティ等事業」に入っている可能性が高い。

もしそうなら:
- MMO系列は**純粋にK4aを追っている**ことになり、ライセンスの増減に汚染されていない（分析上はむしろ都合がよい）
- K4bは **MMO売上の内訳ではなく、MMO売上の外側にある別項目**として推定する必要がある

**計上区分の確定はPhase 2の最優先課題。**

## 3. MMO事業売上の分離問題（重点課題）

スクエニHDが開示する「MMO」サブセグメントには少なくとも以下が混在する:

- FFXIV（サブスク／拡張パッケージ／オプションサービス＝モグステーション。**ライセンスは含まれない可能性が高い** — 第2-3節）
- ドラゴンクエストX オンライン（サブスク／拡張パッケージ／バザー等）。**【Phase 1で確認】DQXオフライン（2022年9月発売）はHDゲームズ計上でMMOに含まれない**
- FFXI（サブスク／オプション）
- 各タイトルの**拡張発売時期が異なる**ため、四半期の凸凹の帰属先が違う

**【Phase 1で判明した分離の手がかり】** 拡張発売四半期を除いた四半期売上（＝経常収益ベースライン）を恒常為替で見ると、FY2017.3の57.6億円からFY2022.3の139.2億円まで上昇し、FY2026.3には90.3億円まで低下している。**この階段はFFXIVの拡張世代とよく対応しており、MMO売上の大半をFFXIVが動かしていることの傍証**になる（DQXの拡張はベースラインをほとんど動かしていない）。

### 3-1. 分離手法（主）: 制約充足型分解

回帰は自由度が足りない（タイトルあたり拡張n≈5、古い期は開示粒度が粗い）ため、**上から積み上げず、制約を積んで解を絞る**方式を主とする。

1. **拡張パッケージ売上を直接見積もる**
   - FFXIV: Steamレビュー数比、公式発表の販売本数・登録者数コメント、同時接続の初動
   - DQX: ファミ通実売ランキング（パッケージ版）、公式の販売コメント
   - 推定販売本数 × 価格帯 = パッケージ売上の帯
2. **サブスク定常収入（ベースライン）を残差として求め**、タイトル別の活動規模比で按分
3. **FFXIを上限で押さえる**（サービス規模の公式言及、開発体制の縮小から上限を設定）
4. **会社の定性発言を制約条件に使う**（決算説明会 質疑応答要旨の「MMOの大半がFFXIV」型の発言、拡張発売期の増減理由説明）
5. **為替影響を分離**（FFXIVは海外比率が高く、円建て売上は為替で膨らむ／縮む）→ 恒常為替ベースの系列を併記

### 3-2. 分離手法（補助）: イベントダミー回帰

上記の帯が妥当かの**検証用**に限って使う。回帰結果を主推定に採用しない。

### 3-3. 成果物の形

FFXIV売上の**推定レンジ（上限・下限を持つ帯）と信頼度ランク**。単一の点推定は出さない。

## 5. データ品質ルール

すべての数値に以下のタグを付与する:

| タグ | 意味 |
|------|------|
| `[Fact]` | 一次資料に明記された数値 |
| `[Observed]` | 第三者による観測データ（国勢調査、SteamDB等） |
| `[Company]` | 会社側の見通し・ガイダンス・定性説明 |
| `[Estimate]` | 本分析による推定値（算出根拠を必ず併記） |
| `[Hypothesis]` | 検証前の仮説 |

**禁止事項**:
- 「Dawntrailが不評だから終わり」「吉田Pがいるから安泰」のような単線的断定
- 出典不明の数値の引用
- **【Phase 0.5で追加】「独立裏取り」の誤用。** 同一作成者の産物どうし（国勢調査のスプレッドシート ↔ 同じ記事本文）や、同一資料から書かれた記事どうし（決算説明会資料 ↔ それを報じた記事）の突合は**「転記検証」**であって独立検証ではない。`[Fact]` への昇格条件は「転記検証済み ＋ 一次資料の現物確認」
- **【Phase 0.5で追加】逆算値を検証済みとして扱うこと。** 同じ資料の水準と増減率から出した逆算は内部整合チェックにすぎず循環している。前年資料の現物で照合する
- **【Phase 0.5で追加】汚染された観測点を無調整でキャリブレーションに使うこと。** 例: 有料会員70万超 vs census 101万 → 比1.44 は、(a)「70万**超**」が下限なので**比の上限**にすぎず、(b) 分子は系列中で最も汚染された観測点（キャンペーン＋123日窓）である
- 単一点予測での結論提示（必ずBear/Base/Bullのレンジ＋確率加重）
- 直近トレンドの単純外挿のみによる3年予測（拡張サイクルの周期性を必ず考慮）
- **累計登録者数（「累計○○万プレイヤー」）を実勢アクティブと混同すること**
- **推定値を後続Phaseで既成事実として扱うこと**（タグを剥がさない）
- **変換係数を定数扱いすること**（ワールド統合・無料転送・新ワールド開設ボーナスはサブ垢比率を動かす）
- **異種指標間でカーブ形状を比較すること**（国勢調査 vs Steam CCU vs レイドログ参加者は、同一人口でも減衰の形が違う。比較は必ず同種指標のペアで行う）
- **参照クラスを生存タイトルだけで構成すること**（回復ベースレートが構造的に上振れする）
- **【Phase 3.5で追加】基準改定をまたぐ系列を接合すること。** NCSoft は2026年5月に CY2025 を遡及修正し、4タイトル合計で +17.7%（タイトル別に +3.9%〜+34.3%）ずれた。旧基準の分母と修正後の分子を割ると偽の減衰率になる（実際に Phase 3.5 v0.1 が犯し、Lineage II の符号が反転していた）。**「more than X」の下限値と点推定の混在も同種の禁止**（下限値を分母に置いた減少率は下界としてのみ記述する）
- **【Phase 3.5で追加】月次CCUの単月比較で拡張効果を論じること。** 最小単位は12ヶ月窓。単月では Destiny 2 の結論が反転する

- **【Phase 3.5で追加】異なる関数形の数値を並べて「食い違い」と呼ぶこと。** post/pre窓比とピーク→直近比は別物。Phase 3.5 v0.1 はこれで偽の未解決課題を1件作った
- **【Phase 3.5で追加】事後に最長世代（最悪期）を特定して「その次は下がった」を頻度として数えること。** 系列が単調増加でない限り定義的に成立する準トートロジーであり、ベースレートにならない
- **【Phase 4で追加】カテゴリ別の定義変更効果を、総数用の一律係数で補正すること。** 2026-07-20 の同日ペアで実測すると、足切り引き上げの効果は 総数 −6.9% に対し **新規 −37.5%・復帰 −9.7%・継続 −3.2%** と5倍以上開く。新規の世代間比較に総数用の係数を当てると結論が反転しうる
- **【Phase 4で追加】窓長の異なる期間どうしで生のフロー数を比較すること。** 世代別平均窓長は 64.5〜73.0日と最大13%違う。必ず64日換算する
- **【Phase 4で追加】継続数の減少を定着率の低下と読むこと。** 継続数はプールの大きさにも依存する。定着率を語るには再捕捉率を**今回窓長・前回窓長の両方**で統制する必要がある（前回窓長の方が有意: t=−2.37）
- **【Phase 4で追加／Phase 8で改訂】ρ（定着率）と I（流入）を独立に動かすこと。** 再捕捉率は前回フロー比率に負に依存する（**係数 −0.301、t=−0.95。Phase 4 v0.2 の −0.51 は定式化欠落＋窓長汚染の合成値**）。**流入が回復すればプール組成がフロー寄りになり定着率は機械的に下がる。** 独立分布として掛け合わせると上振れシナリオを系統的に過大評価する。**ただし逆に、この項を時系列の構造方程式として外挿することも禁止する**（下記 Phase 8 の追加項目）
- **【Phase 5で追加】拡張サイクルの位相を揃えずに施策の効果を測ること。** Xbox版の「新規0.56倍」は、7.0発売4ヶ月後の谷を発売前と比較して生じた人工物だった
- **【Phase 5で追加】検出力を示さずに「有意でない」を「効果なし」と読むこと。** z<2 の不在は、検出限界を明示して初めて意味を持つ（Phase 5 のイベントスタディの検出限界は単月 −25〜−39%）
- **【Phase 5で追加】効果が実証されていない変数の不在を上振れ要因として積むこと。** 「WoWと競合しないから8.0は有利」は、そもそもWoW衝突の効果が実証されていない以上、二重カウントに相当する
- **【Phase 6で追加】窓長汚染された生の国勢調査系列を回帰の説明変数に使うこと。** corr(窓長, 生census)=+0.516。測定誤差により回帰係数が減衰バイアスで過小になる。**本プロジェクトでは、このバイアスは一貫して「衰退はマイルド」という結論に有利な方向に働いた**（Phase 6 で弾力性が 0.67→0.77 に修正された）
- **【Phase 6で追加】同一データに関数形を2つ当てて「独立の検証」と呼ぶこと。** 線形の点弾力性と log-log 回帰が標本平均近傍で一致するのは代数的にほぼ自明。独立の検証には別データ・別標本・別識別戦略のいずれかが要る
- **【Phase 6で追加】in-sample のバックテスト結果を、out-of-sample の検証であるかのように提示すること。** 真の out-of-sample と必ず併記する（Phase 6 では in-sample 4/4 に対し out-of-sample は 2/4 だった。**さらに Phase 8 で足切り基準を統一して測り直すと 0/4 になり、水準モデルは外挿に使えないと判明した**）
- **【Phase 6で追加】施策・イベントのフラグを、実際に該当する期と該当しない期を混ぜたまま平均すること。** Phase 6 の「拡張四半期パルス」は、発売のない6観測が混ざって +42.2億 → +22.1億 と半減して見えていた
- **【Phase 7で追加】モデルの出力が望ましくないことを、入力パラメータ変更の根拠にすること。** Phase 7 v0.1 は検算ログに「ρ が上昇して K1 が増える誤った結果を出した → 基準値を修正」と自ら記録していた。**これは precommit が防ごうとした過剰適合そのものである**
- **【Phase 7で追加】事前分布に自モデルが含まれている状態で、自モデルとの一致を「独立の検証」と呼ぶこと。** Phase 4 §4-3 の事前分布は自モデルを重み0.45で含んでおり、Phase 7 v0.1 の「独立に一致した」は循環論法だった
- **【Phase 7で追加】モデルが予測する値そのものを、シナリオの分岐判定の閾値にすること。** どんな観測結果もシナリオを反証できなくなる。閾値はモデルと独立に、重複のない帯として事前に定義する
- **【Phase 8で追加】回帰の定式化を文書に記述する際、実際に推定した式と異なる記述をすること。** Phase 4 §2-4 の定式化③④は「②＋前回フロー比率」と書かれていたが実際は「①＋前回フロー比率」で、`log(前回窓長)` が落ちていた。**同じ節の直前で自ら「①は誤った定式化」と断じた上に積んでいた。本プロジェクト最大の単独の誤り**（ρ(7.x) 0.722→0.764、予測の中心値が15pt動いた）
- **【Phase 8で追加】結論を動かす係数を、再現スクリプトに入れずに文書へ転記すること。** 転記された時点で検証不能になる。**上記の定式化欠落は、Phase 8 でスクリプト化して初めて露見した**
- **【Phase 8で追加】位相の異なる年度どうしを比較して増減率を出すこと。** 拡張の発売年度と非発売年度の比較は位相の産物を生む。同じ Base シナリオが基準の取り方で **−16.5% / +12.6% / −2.0%** と振れた
- **【Phase 8で追加】断面回帰の統制変数を、時系列の構造方程式として外挿すること。** ρ–I 結合を外挿すると `S*=I/(1−ρ)` の双曲性と組んで正のフィードバックになり、係数の CI 内でモデルが発散する（fs→0 の極限 ρ が 1.015）。かつ「**新規獲得が枯れるほど人口が増える**」という帰結を生む
- **【Phase 8で追加】足切り基準を統一せずに、観測レンジによる外挿判定・年度平均の比較・回帰の説明変数化を行うこと。** 生の `normalized_64d` は窓長のみ正規化されており足切りは生のままである。統一すると観測レンジは 584,496〜1,524,252 → **471,662〜1,321,162**、FY2026.3 年度平均は 877,538 → **816,988** になる。**本プロジェクトで単一で最も再発した誤り（6 Phase で違反）**
- **【第7次監査で追加】制約条件を文章で宣言し、計算がそれを満たしているか確かめないこと。** 「加法制約 new+ret+cont = total を課した」と書いた感度が、実際には新基準で 1.0万・旧基準で 2.0万 制約を破った隅で計算されていた（幅が 8.3pt → 15.3pt に膨らんでいた）。**制約は宣言ではなく、計算の出口の assert で担保する**
- **【第7次監査で追加】検査ツールを新設したとき、そのツールが既知の誤りを検出できることを確かめずに「検査で問題なし」と言うこと。** 新設した機械チェッカーは「致命 0」を出したが、撤回済み主張5件を訂正マーカーなしで注入しても検出 0 件だった（免除条件が広すぎ、全非空行の 61% を免除していた）。**検査器には自己テストを組み込む**
- **【第7次監査で追加】文書の数値を一括置換で更新すること。** 第7次の訂正作業で、実際に `phase8-verification.md` の版数履歴表（「その時点で何と書いたか」の記録）を現行値で上書きしてしまった。**履歴表・監査記録・由来追跡用の表は一括置換の対象外とする**
- **【第7次監査で追加】ある量の「基準がずれている」と気づいたとき、正しい値を併記するだけで正典を差し替えないこと。** ローンチ倍率 1.86 は分母がモデルの掛ける量と違うと第6次で認定されながら、正典は 1.86 のままで、予測もバックキャストもそれで回っていた。正典 1.729 に差し替えると主指標が 0.7pt、上方バイアスが 0.9pt 動いた
- **【第6次監査で追加】結合でしか制約されない2つの量を、それぞれの周辺レンジで独立に振って「分散源の順位」をつけること。** バックキャストが制約するのは `S* = I/(1−ρ)` であって ρ でも I でもない。周辺レンジ (0.74, 0.80) / (140k, 200k) は結合許容集合の**射影**であり、その端点は相手を最適に選べば到達できる点である。相手を採用値に固定して端点へ振ると結合制約を外れる（実際9点すべてが域外だった）。**機械的な検出法: 一度に1つ振った幅が、同じ制約下の同時スキャンの幅を超えていたら較正が壊れている**（27.7pt > 14.0pt で発覚）
- **【第6次監査で追加】検証手続き自身のメタパラメータ（格子の刻み・許容率・振る対象・除外の選び方）を、宣言せず感度も取らないこと。** S\* 許容域は Δρ=0.02 の粗格子と「MAE 最小の1.5倍」という無根拠の許容率に依存しており、細格子にすると**本レポート最大の留保が反転した**。足切り丸めも「4成分のうち total だけ振る」という未宣言の選択で幅が 7.3pt → 8.3pt に変わった

- **【第6次監査で追加】ある欠陥を1箇所で直したとき、同型の欠陥を同一ファイル内ですら探さないこと。** 第5次 C7 は T10 の「7万超」を達成不能として撤回したが、**同じスクリプトの T4 が同じ量・同じ閾値を保持していた**。第5次 C3 は「Bear は t=0 から分離」を人工物と認定したが、**同じスクリプトの20行下の T1 判定条件にその主張が残っていた**

- **【Phase 3で追加】「本数ベースの供給密度」を「コンテンツ量」と読み替えること。** パッチ本数は搭載コンテンツ量ではない。1本が重くなった可能性を排除してから量の議論をする
- **【Phase 3で追加】施策を一律プラスとして扱うこと。** 例: デイリー→ウィークリー化は離脱理由を1つ消す一方、日次ログイン習慣という課金継続の防波堤も壊す。**KPIへの符号を機能ごとに明示する**

- **【Phase 2で追加】継続キャラ数を今回窓長だけで補正すること。** 前回窓長（母集団プール）のほうが強く効く。片方だけの補正は誤った結論を生む
- **【Phase 1で追加】名目の円建て売上で増減を論じること。** USD/JPYはFY2013.3の83円からFY2026.3の151円へ約1.81倍、EUR/JPYは1.63倍。名目ではFY2026.3のMMO売上410億円が漆黒期（401/398億円）と同水準に見えるが、恒常為替では**350億円 対 411億円**（s=0.58、Phase 6 の採用値）で明確に下回る。**以降のすべての分析で恒常為替系列を主とする**

### Phase 2 — プレイヤーデータ基盤の構築 ✅ **完了（v0.2）**
> **【Phase 0.5で判明】** データ取得は `gviz` 経由のCSVで機械的に完了する（2017/6〜2026/7の49時点、ワールド粒度）。本Phaseの重量は「書き写し」ではなく **窓長正規化と要因分解という判断作業** にある。

**最優先処理①: 調査間隔（窓長）の正規化**
「アクティブ＝前回調査から変動があったキャラ」という定義上、カウントは調査間隔（35〜123日でばらつく）の増加関数になる。実測で **corr（間隔, 変化率）= +0.745、corr（間隔, 水準）= +0.516**（全期間で正）。**これを正規化しないと、以降の全分析が観測アーティファクトを追うことになる。** 調査間隔を共変量として明示的にモデル化する（パッチ位相 × 窓長の同時推定）。既存の「パッチ経過日数軸」だけでは窓長効果は除去できない。

**最優先処理②: 2026年反発の4要因分解**
2026/4/19（771,486, 55日窓）→ 2026/7/20（955,708, 92日窓）の+23.9%を、**窓長効果／フリーログインキャンペーン効果／定義変更（減算方向）／実回復** に分解する。ここの結論が Phase 4・7 の全体を左右する。8.0発表・パッチ7.5・ファンフェス2回が同一窓内にあるため個別要因の切り出しは原理的に不可能である点も、結論に明記する。

**最優先処理③: 継続系列の飽和モデル推定（K1bの検証）**
「継続キャラ数は窓長に頑健」という直感は**誤り**（Phase 0.5で反証済み）。再捕捉率＝継続_t ÷ 前回総数 は窓長に単調増加する（55日:0.685 / 64日:0.737 / 85日:0.789 / 92日:0.791）。目視の「水準が平ら」では、プール効果と再捕捉率効果の相殺アーティファクトを検出できない。
→ **継続_t = 前回総数 × f(w_t) の飽和モデルを、内訳が取れる全回で推定し、f の形と残差トレンドを見る。** 交絡として、プロフィール公開設定の変更、キャラ削除・ワールド移転、サブキャラ整理（アカウント数が一定でもキャラ単位の継続は減る）を列挙して扱う。
また **内訳の加法性（新規＋復帰＋継続＝総数）が合わない回がある**（2026-04-19で残差3.1万＝丸め限界超）。**解消するまで内訳を論拠に使わない。**

**最優先処理④【Phase 1から追加】: 正規化モデルの合格判定**
Phase 1 で財務との突合基準ができた（Phase 1 §7）。**突合は「窓中点」で四半期に割り当てる**（調査日でそのまま当てると系統誤差が入る）。窓中点割り当て・拡張四半期除外の35観測で、**生の census と恒常為替MMO売上は 水準相関 +0.916 / 変化率相関 +0.507**。
→ **窓長正規化後の census 系列は、変化率相関が +0.507 から改善しなければならない。** ただし:
- 「有意に」の検定手順（Steiger検定またはブートストラップ）を**事前に固定する**
- **正規化パラメータを財務相関の最大化で選んではならない**。正規化は census 内部の情報（窓長回帰）だけで決め、財務突合は1回限りのホールドアウトとして使う
- **達成上限は1ではない**。売上側のDQX/FFXI変動、活動と課金のデカップリング（月額契約の慣性）により天井がある

**追加タスク【Phase 1から引き継ぎ】**
- **ライセンス／ロイヤリティ収入の帰属セグメントの確定**（最優先。ライツ・プロパティ等事業のFY2026.3急増との関係）
- 有報注記の契約負債（前受金）残高の確認
- **国勢調査の地域別（JP/NA/EU/OC）構成から、MMOサブセグメントの実効海外比率 s_t^MMO を構築する**（DQX≈国内、FFXIVの地域ミックスから）。Phase 1 では DE事業の47% を代理指標として使ったが、MMOの実際の比率はこれより高い可能性が高い

**運用ルール**: スプレッドシートは遡及修正される（2026年の7.5再集計で実証済み）。**取得日ごとの版管理付きスナップショットを保存する。** あわせてWayback等で7/20記事の再集計"前"の数値を確保する（定義変更効果の直接測定値になる）。

代替として使える定量証拠は3点のみ: (1) パッチ間隔の短縮（SL 228日 → DF 172日、−24.6%。公式日付のみで構成でき最も改竄されにくい）、(2) WarcraftLogs Mythicパース数（TWW S1 492k → Midnight S1 780k、+58%。ただしDPSパース数であり装備入手容易化が交絡）、(3) ATVI Q2 2023 の一次定性証言（西側継続率が近年のModern拡張の同時期を上回る。比率・基準は非公表）。

**「回復のベースレート」は WoW 単独では確立できない。** Phase 3.5 は代わりに Destiny 2（Steam CCU で完全に測定可能）を主な反例事例として採用した。

**Destiny 2 を追加**（MMOではないが拡張サイクル＋シーズン課金で構造が近く、Steam CCUが完全公開）: **Lightfall（不評, 2023）→ The Final Shape（高評価, 2024）で批評的回復が人口回復に繋がらなかった**事例は、RQ8の「回復しても戻らない部分は」に対する直近の有力なエビデンス。

**韓国・中国市場のMMO一般論は参照クラスに入れない**（市場・課金文化が違いすぎ、誤用リスクが上回る）。NCSoft等は「市場比較」ではなく**開示データ源**として割り切って使う。

#### 方法論上の原則と落とし穴

- **水準ではなく「形」を比較する。** 絶対数を並べても意味がない
- **正規化は2方式を常に併走させる**: (i) 拡張リリースからの経過月数、(ii) サイクル位相（0→1で正規化）。サイクル長が違う事例（FFXIV 約2〜2.5年、WoW 約2年で短縮傾向、ESO 年次、OSRS/EVE は「拡張」の区切り自体が薄い）を経過月数だけで重ねると、比較しているのは「維持率の形」ではなく**サイクル長の違い**になる。逆に位相正規化だけだとコンテンツ供給密度の違いが混入する。**結論が正規化方式に依存しないかを必ず確認する**
- **落とし穴E（最大）— 指標種別の混在**: 国勢調査（約1.5ヶ月窓のストック指標）、Steam CCU（瞬間値）、Raider.io/WarcraftLogs（エンドゲーム参加者のサブセット、シーズンリセットで鋸歯状に動く）は、**同一人口でも減衰カーブの形が全く違う**。レイド参加者系列は「コンテンツを消化し終えた」だけで急減するため、人口が一定でもカーブは急落して見える。指標種別を揃えずに形を比較すると、「人口動態の形」ではなく「観測指標の性質の形」を比較することになる
- 各事例について「**FFXIVと似ている点／決定的に違う点**」を必ず明記する
- **WoWの数値には特に厳格な出典管理を課す。** 非開示化以降、AI生成と思われる低品質な「player count 統計サイト」が大量に存在し、相互引用で数字が独り歩きしている。一次・準一次に該当しないものは一切使わない

  2. **サイクル正規化値**（拡張ピーク比の維持率、谷底水準）
