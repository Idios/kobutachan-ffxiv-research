## 2. 【本Phase最大の発見】窓長の影響はカテゴリで全く違う

### 2-1. 実測

新規／復帰／継続の内訳が取れる観測について、対数弾力性 `log(指標) = a + β·log(窓長)` を推定した。

> **【第15次で標本サイズを明記】下表は n=42（前回窓長が取れる部分標本）である。** 内訳が取れる観測は 43 あるが、`log(前回窓長)` を統制項に入れるため1点落ちる。**本文が「43観測について推定した」と書きながら表は n=42 の値だったので、両者を分離する。** n=43（統制なし）では 復帰 +1.074 / 新規 +1.035 / 継続 +0.278 / 総 +0.559、n=42 では 復帰 +1.083 / **新規 +1.197** / 継続 +0.218 / 総 +0.540 となり、**新規だけ 16% 違う**（§10 の「判明した事実」は n=43、§5-1 は n=42 を引いている）。

| カテゴリ | β（窓長弾力性） | 95%CI | R² | **拡張・パッチ統制後のβ** | 解釈 |
|---------|---------------|-------|---|------------------------|------|
| **復帰** | **+1.08** | [+0.50, +1.66] | 0.25 | **+1.11** (se 0.31) | 窓長にほぼ**比例** |
| **新規** | **+1.20** | [+0.53, +1.87] | 0.23 | **+1.30** (se 0.34) | 窓長にほぼ**比例** |
| **継続** | **+0.22** | [−0.10, +0.54] | 0.04 | **+0.28** (se 0.16) | ほぼ**非感応** |
| 総アクティブ | +0.54 | [+0.23, +0.85] | 0.22 | +0.60 (se 0.16) | 中間 |

**信頼区間は広い。** データ単独では復帰β=0.5もβ=1.6も許容する。**構造的断定を支えているのは「フローは窓に比例する」という理論的な事前分布**であり、データはそれと整合的だが決定的ではない。

**交絡の検証（イベント統制）**: 窓長がパッチ周期と相関し、係数がイベント効果を拾っているだけではないか、という懸念に対して、拡張ダミーとパッチ本数を投入して再推定した。**フロー≈1.1〜1.3／ストック≈0.28 という序列は保存される。** さらに拡張と同じ窓は平均55日で、通常の72日より**短い**（corr(log窓長, 拡張)=−0.29）。したがって「窓長係数はイベント効果の代理」という説明は棄却できる。

### 2-2. なぜこうなるか（構造的な説明）

- **復帰・新規は「窓の中で起きた出来事」を数えるフロー指標。** 観測窓が2倍になれば、その間に復帰／新規登録する人数もおよそ2倍になる。**弾力性1は理論値どおり**
- **継続は「前回もアクティブだった人が今回も観測されるか」というストックの再捕捉。** 窓が延びても母集団は増えず、増えるのは「頻度の低い層まで拾える」分だけなので飽和する

**この構造が、Phase 0.5 で見た「総アクティブの変化率が窓長と相関する（+0.745）」の正体である。** 総アクティブは非感応なストック（継続）と比例するフロー（新規＋復帰）の合成で、フローの比率が高い回ほど窓長に振り回される。

### 2-3. 正規化モデル

上記から、正規化は次の形になる:

```
正規化済み活動キャラ数 = 継続 + (新規 + 復帰) × (64 / 窓長)
```

（64日＝調査間隔の中央値）

**このモデルは国勢調査の内部情報だけで決めている。** 財務データは一切使っていないので、財務との突合をホールドアウト検証として使える（Phase 1 §7-6 の手順どおり）。

継続にも弱い窓長感応（β=0.277）があるが、R²=0.072 と説明力が低いため主モデルには入れない。感応度として別途評価した。

## 3. 正規化モデルの合格判定 — **事前基準では不合格（暫定採用）**

Phase 1 §7-6 で定めた手順に従い、財務データ（恒常為替MMO売上、窓中点割り当て、拡張四半期除外）との相関で判定した。

|------|---------|-----------|--------------|
| 生の総アクティブ | **0.929** | 0.562 | [0.319, 0.717] |
| **正規化A（流量のみ日次換算）** | 0.901 | **0.645** | [0.377, 0.839] |
| 正規化B（継続にも弾力性補正） | 0.861 | 0.650 | [0.357, 0.842] |

（n=32。同一データ上の従属相関なので、ブートストラップ4,000回でペアリングを維持して評価）

**改善幅のブートストラップ（正規化 − 生）**

| | 中央値 | 95%CI | 改善確率 |
|---|-------|-------|---------|
| A | **+0.088** | [−0.130, +0.342] | **81.2%** |
| B | +0.087 | [−0.189, +0.360] | 76.0% |

### 判定

Phase 1 §7-6 の事前基準は「**点推定の改善＋ブートストラップCIで劣化を否定**」だった。CIが0を含む以上、**劣化を否定できていない＝事前基準では不合格**である。

「部分的合格」という第三のカテゴリを事後に作るのは事前登録の意味を薄めるので、**「事前基準未達。構造的根拠により暫定採用し、次回データで再判定する」**と表記する。

**また、水準相関はむしろ低下している**（0.929 → 0.901）。正規化は変化率の追随を改善する代わりに、水準にノイズを加えている。内訳が万単位の概数であることが効いていると見られる。

### この結果をどう扱うか

1. **正規化Aを暫定的な標準系列として採用する。** 構造的な根拠（フロー vs ストックの弾力性差、しかもイベント統制後も保存される）があり、点推定も改善しているため。**次回国勢調査のデータで再判定する**
2. **ただし「正規化すれば窓長問題が解決した」とは言わない。** n=32、CIが0を含む
3. **水準の分析には生系列も併用する**（水準相関は生のほうが高い）
4. **達成上限は1ではない。** 売上側のDQX/FFXI変動、活動と課金のデカップリング（月額契約の慣性）により天井がある

## 4. 2026年の「急反発」の要因分解 — Phase 0.5 からの最重要課題

> **v0.1で算術ミスがあった。** ②の起点に、総数へ比例配分する前の概数内訳（合計74万）を使っており、①の分母（全桁771,486）と不整合だった。残差は+16.3%ではなく**+12〜14%**。あわせて、順序依存を避けるため**log分解**に置き換えた。

### 4-1. log分解（順序独立）

| 段階 | log寄与 | 水準 |
|------|--------|------|
| **公表値** 771,486 → 955,708 | **+0.214** | **+23.9%** |
| ① **定義変更**（Lv80超化）を戻す | **−0.071** | 反発を**小さく**見せていた |
| **基準統一後** | +0.285 | **+33.0%** |
| ② **窓長**（55日→92日、流量を64日換算） | **−0.135 〜 −0.152** | |
| **正規化後** | +0.134 〜 +0.150 | **+14.3% 〜 +16.2%** |
| ③ **フリーログインキャンペーン**（5/15〜6/14の30日が窓内） | **−0.024** | |
| ④ **残差（実回復＋施策）** | **+0.110 〜 +0.127** | **+11.6% 〜 +13.5%** |

②と④に幅があるのは、7/20の正規化値をLv70超基準に戻す方法が2通りあるため（新旧比102/95を掛ける方法 = 916,491／旧基準の内訳から直接計算する方法 = 901,304）。

**数値の精度について**: 旧基準の102万・新基準の95万はいずれも万単位の概数である。**−6.9%という定義変更効果自体が −5.9〜−7.8% の幅を持ち、基準統一後の値も ±1ポイント強のばらつきを持つ。** 小数1桁の精度で語れる数値ではない。

### 4-2. キャンペーン効果の感度 — 最大の不確実性

③のキャンペーン寄与（約21,000キャラ）は **R²=0.048 の回帰**から出しており、説明力が極めて低い。しかも**下限寄りの推定である可能性が高い**: 本書が引用している2019年の類例では、Twitch Prime無料配布により新規が約3倍（7万→23万）に膨らんでいる。

残差にはパッチ7.5（4/28）、8.0『白銀のワンダラー』発表（4月末 北米ファンフェス）、欧州ファンフェス（7月）、そして純粋な実回復が**分離不能な形で**含まれている。すべて同じ92日の窓に入っている。

## 5. コア層（継続）の縮小 — 総アクティブより速いが、当初の見立てほどではない

> **v0.1では「−38%」「流量比率0.351は突出」「単調な減少」と書いた。いずれも過大または誤りだったので訂正する。**

### 5-1. 前回窓長（プール効果）の統制が必要だった

Phase 0.5 §1-6.5 が自ら警告していた論点を、v0.1 は落としていた。**継続_t は今回の窓長 w_t だけでなく、母集団プール（＝前回総数、これ自体が w_{t−1} に汚染されている）にも依存する。**

実測すると、**前回窓長のほうが効く**:

| モデル | β（今回窓長） | β（前回窓長） | R² |
|--------|-------------|-------------|---|
| log継続 ~ log今回窓長 | +0.218 (se 0.164) | — | 0.042 |
| **log継続 ~ log今回窓長 + log前回窓長** | **+0.404** (se 0.151) | **+0.511** (se 0.136) | **0.297** |

R²が0.04から0.30に跳ね上がる。**2026/7/20の直前調査（4/19）は系列最短の55日窓だった。前回窓で取りこぼされた人は、次回「継続」ではなく「復帰」に分類される。** つまり2026/7の「継続が低く復帰が突出」には、相当量の**分類アーティファクト**が含まれている。

### 5-2. 二重補正（今回窓・前回窓の両方を64日に）した継続系列

| 調査日 | 今回窓 | 前回窓 | 継続（二重補正・基準統一後） |
|--------|-------|-------|------------------------|
| 2024-06-12 | 73 | 98 | 700,165 |
| **2024-08-27** | 76 | 73 | **890,414（直近のピーク）** |
| 2024-11-04 | 69 | 76 | 889,087 |
| 2024-12-29 | 55 | 69 | 854,286 |
| 2025-05-25 | 70 | 77 | 654,994 |
| 2025-09-27 | 62 | 63 | 674,961 |
| 2025-11-30 | 64 | 62 | 663,906 |
| 2026-02-23 | 85 | 64 | 588,832 |
| 2026-04-19 | 55 | 85 | 613,626 |
| **2026-07-20** | 92 | 55 | **621,450**（Lv70超基準に統一） |

**ピーク890,414 → 直近621,450 で −30.2%。** v0.1 の −38% は前回窓長を統制していなかったための過大評価だった。

> **【Phase 3.5 による外部裏付け（v0.4で追記）】** この −30.2% は、まったく別系列である **Steam月次ピークCCU によって独立に裏付けられた**。同一区間（2024-08 → 2026-07）で Steam は **−40.7%**、正規化済み総アクティブは **−33.3%**（足切り統一後）、継続は −30.2%。**Steam の方がむしろ速く落ちている。**

> **【第15次で訂正】** 旧記載の「正規化済み総アクティブ −37.9%」は足切りレジーム混在（分子 Lv80超／分母 Lv70超）だった。段差 0.9303 で揃えると **−33.3%**。**継続 −30.2% は Lv70超に統一済みなので、混在のまま並べてはならなかった**（D-4）。
> **なお §5-2 の「コアは総アクティブよりやや速く縮んでいる（−30% 対 −29%）」は生系列規約での比較であり、norm64＋足切り統一の規約では総アクティブ −33.3% 対 継続 −30.2% で向きが逆転する。この結論は規約依存である。**
> Phase 3.5 §2-2 は、2020年以降 Steam CCU と正規化済み国勢調査の比が 0.032・CV 24.9% で安定し、±4%/年超のドリフトを棄却できることを示した。**したがって本節の減少幅は、国勢調査の方法論に起因する人工物ではない。**
> **ただし関数形を揃えること**（Phase 3.5 §2-4 所見4 の教訓）: 同じ区間・同じ関数形で比較して初めてこの一致が見える。拡張post/pre の12ヶ月窓で見ると Steam 0.937 / 正規化済み国勢調査 0.989 で、**どちらも「7.0後の最初の1年はほぼ横ばい」**。減少は2024年秋以降に集中している。

→ **`[Hypothesis]` コアは総アクティブよりやや速く縮んでいる（−30% 対 −29%）が、「遥かに速い」とは言えない。差は数ポイントである。**

## 7. 内訳の加法性（M9）— 解消

2026/4/19 で「新規4万＋復帰6万＋継続64万＝74万」が総数77.1万と3.1万合わない件。

**全49回で加法性をチェックした結果、内訳が揃う47回のうち46回は差が±1万以内**（万単位丸めで説明可能）。**3万ずれるのは2026/4/19だけ。**

記事の該当文は自己完結して整合しており（6−2=4、21−15=6、93−16=77）、転記ミスではない。休止／引退／削除といった第4のカテゴリ語は本文に登場しない。

決定的なのは著者自身の但し書き:

> 「厳密には前回復帰した全員が休止したわけではないし、継続していた中でも休止した人もいるので**あくまで規模感で見た場合**」

**内訳は厳密な分割ではなく規模感の概算として提示されている。** 2026/4/19 の3.1万は丸め幅を超えるが、この1回だけの現象であり、**当該回は内訳ではなく総数を基準に使う**方針で扱う。

> **【第15次で判定基準を訂正】上の「3項で最大 ±1.5万」は四捨五入前提の丸め幅である。** 第8次で万表記が**切り捨て**と実証されたので、正しい理論域は **(−1万, +3万)** で**非対称かつ系統的に負に出る**（各項を切り捨てた和は、総数の切り捨て値より小さく出る —— `params.py` が「切り捨て特有の現象」と明記）。
> **したがって「46回は差が±1万以内だから万単位丸めで説明可能」という検定は、規約が違うため妥当な検定になっていない。** ただし 2026/4/19 は切り捨て規約でも例外である（40,000+60,000+640,000 の上限 769,999 < 771,486）ので、**結論「内訳は規模感の概算」は変わらない。**

なお、本Phaseの正規化では内訳を**総数に比例配分してスケーリング**してから使っており、この不整合の影響は除去されている。

## 10. 判明した事実 / 重要な発見 / 仮説の変化 / 未解決事項

### 判明した事実
- 足切りレベルは 21 → 36 → 60超 → 70超 → 80超 と4回引き上げられた。すべてカウント減少方向
- 定義変更の効果が直接測れるのは 2026/7/20 の1回のみで **−6.9%**
- 窓長弾力性は 復帰 +1.072 / 新規 +1.034 / 継続 +0.277 / 総アクティブ +0.558
- 内訳の加法性は47回中46回で成立。著者自身が内訳を「規模感」と明言
- アクティブ判定条件には「マウント1体以上所持」「FC所属」が実在する
- ライセンス収益はデジタルエンタテインメント事業に計上（ライツ・プロパティ等ではない）
- 繁体字版は2025/12/10開始、発行代理権の供与、PC版のみ、新規サーバー
- 中国本土版・韓国版はいずれもグローバル同期化の方向で継続中
- 2024/8/27〜11/4 に Lodestone のキャラクター情報を非公開にできるようになり、母集団自体が縮小した（JP非公開率3%）

### 重要な発見
1. **【最重要】窓長の影響はカテゴリで全く違う。** フロー（新規・復帰）は窓長にほぼ比例、ストック（継続）はほぼ非感応。**これが「総アクティブが窓長に振り回される」構造の正体**であり、正規化の設計根拠になる
2. **2026年の反発には実体成分がある。** log分解の残差は **+12%前後（幅 +4〜14%）**。財務側の推定（FFXIV分 +11%）と同じオーダー。**Phase 0.5 の「窓長効果が最有力」という判断を更新する**。ただしキャンペーン効果の推定が最大の不確実性
3. **定義変更は反発を小さく見せていた。** 基準統一すると公表 +23.9% は **+33.0%** になる
4. **【v0.1から下方修正】コア層（継続）は総アクティブよりやや速く縮んでいる。** 前回窓長（プール効果）を統制すると、黄金初動後のピーク890,414 から直近621,450 で **−30.2%**（基準統一後の総アクティブは −28.8%）。v0.1 の「−38%」「遥かに速い」は**前回窓長を統制していなかったための過大評価**。差は数ポイントである `[Hypothesis]`
4b. **「2026/7の流量比率が突出」は撤回。** 64日換算すると0.294で全期間平均0.282をわずかに上回る程度。生の比率で長窓の回を「突出」と呼ぶのは、自ら示した「フローは窓に比例する」と矛盾する循環論法だった
4c. **継続は今回窓長より前回窓長に強く依存する**（β_今回=+0.404 / β_前回=+0.511、R²は0.04→0.30）。前回窓で取りこぼされた人は次回「継続」ではなく「復帰」に分類されるため、**短い窓の直後の回は構造的に「継続が低く復帰が高い」**
5. **ライセンス収益がライツ・プロパティ等の急増要因という懸念は消えた。** 急増はMTG×FFコラボであると会社が明言している
6. 正規化モデルの合格判定は**事前基準では不合格**（点推定は改善、CIは0を含む）。構造的根拠により暫定採用し、次回データで再判定する

### 仮説の変化
- （Phase 0.5）2026年の反発は窓長効果が最有力 → **更新**: 窓長は最大の単一要因だが、除去後も +12%前後の残差がある。**実体成分の存在を認める**
- （v0.1）残差は+16.3% → **訂正**: ②の起点に比例配分前の概数内訳を使う算術ミス。log分解で **+12%前後**
- （v0.1）コアは総アクティブより「遥かに」速く縮む（−38%） → **下方修正**: 前回窓長の統制後 −30.2%。総アクティブ −28.8% との差は数ポイント
- （Phase 0.5）継続キャラ数を主指標にすべきか → **決着**: 継続は窓長にほぼ非感応と確認されたが、**流入を1調査分遅れてしか映さない**ため主指標にはしない。K1b（コア動態指標）として併設する方針が正しかった
- （Phase 1）ライセンス収益はライツ・プロパティ等かもしれない → **否定**: DE事業。ライツの急増はMTG×FFコラボ
- （Phase 0.5）2019年の段差の解釈 → **確定**: 型1（再集計ペア）ではなく型2（連続調査値）。定義変更の効果は分離できない
