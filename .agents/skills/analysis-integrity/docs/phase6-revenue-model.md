## 3. 収益モデル

### 3-1. モデル選択の理由 — なぜ完全分解をやらないか

Phase 0 は「収益分解: サブスク＋パッケージ＋オプション」「K1→K2→K3→K4a の変換式を定式化」を求めていた。**本Phaseはこれを実行しない。** 理由は独立制約の調査結果である:

| 障害 | 内容 |

### 4-3. 【v0.2で削除 → v0.7で全面訂正】「限界キャラは平均の1.4%」という記述

v0.1 は「限界 67.4円/四半期は日本の月額 ¥1,628 の **1.4%**」と書いたが、**分母がすり替わっていた**。見出しは「平均キャラの価値より低い」なのに、比較対象が月額定価になっていた。

**【v0.7・第6次監査 R6-15 で訂正】v0.2 が「残る定性的な主張」として保存した「限界キャラの価値は平均キャラの価値より1桁以上低い」は、恒等式に反しており誤りである。**

線形モデル `CC = B + a·K1` の下では、定義から

```
ε ≡ (dCC/CC)/(dK1/K1) = a·K1/CC = 限界単価 ÷ 平均単価
```

が恒等的に成り立つ。本文書の中心推定は **ε ≈ 0.75〜0.85** なので、これは「**限界は平均の約75〜85%**」を意味する。「1桁以上低い（≈0.7%）」は ε ≈ 0.008 に相当し、同一文書内の ε と代数的に両立しない。

原因は §0-A・§0-B が訂正した**単位の100倍ずれ**が §3〜§5 に伝播していなかったことである（正しくは 79.4円 → **7,940円**／足切り統一後の正典は **8,693円**）。検算: 8,693円 × 853,595 ÷ 88億 ≈ 0.84 ＝ ε とほぼ一致する。79.4円のままだと ε = 0.008 になり、回帰が出した ε と3桁ずれる。

**したがって §3-2・§3-3・§4-2・§5-3 に残る「79.4」「67.4」「70.8」「60.5」「82.5」「101.6」円/キャラ/四半期は、すべて 100 倍して読むこと**（下表）。正しい定性的主張は次の通り:

> **限界キャラの売上寄与は平均キャラの約 3/4（＝ε）である。** 平均より低いが、桁は同じである。これは「既存の課金者の一部が離脱しても、残る層の課金や拡張パッケージ売上が水準を支える」という程度の非弾力性であって、「限界キャラにほぼ価値がない」という意味ではない。

| 表記 | 誤（100倍ずれ） | 正 |
|---|---|---|
| v0.1 生census の傾き | 67.4円 | **6,740円** |
| 同・部分標本 | 70.8円 | **7,080円** |
| v0.2 正規化後 | 79.4円 | **7,940円** |
| 一次差分回帰 | 60.5円 | **6,050円** |
| 時間トレンド追加 | 82.5円 | **8,250円** |
| 真OOS（FY2022.3以前） | 101.6円 | **10,160円** |
| **足切り統一後の正典（v0.6）** | — | **8,693円** |

**この誤りの類型**: 根本原因 D-6（桁・単位の sanity check を行わない）が §0-A で名指しで訂正された後も、**同一文書の3節に生き残った**（D-2 との複合）。恒等式 `ε = 限界/平均` は §0 の検算一覧に入れておくべき検出器だった。

## 6. マージンバンド

### 6-1. 【v0.2で撤回】v0.1 の「拡張発売前年に費用先行は観測されない」は位相分類の誤りだった

v0.1 は「発売前年」バケットに **FY2024.3 Q1〜Q4 ＋ FY2025.3 Q1 ＋ FY2027.3 Q1** を入れていたが、**3種類の異なる位相が混ざっていた**:

| 期 | 実際の位相 |
|----|----------|
| FY2024.3 Q1〜Q4 | **真の「7.0発売前年度」**（7.0 は FY2025.3 Q2 発売） |
| **FY2025.3 Q1** | **発売と同一年度の直前四半期**（「前年」ではない） |
| **FY2027.3 Q1** | **発売と同一年度の3四半期前**（8.0 は FY2027.3 Q4） |

**この誤分類のため、バケットの範囲が 28.3〜52.8% に広がり、「費用先行の兆候はない」という結論が導かれていた。**

**さらに v0.1 は、自プロジェクトが保全した一次記録と矛盾していた**:
- `data/mmo_financials_quarterly.csv` の FY2027.3 Q1 行の note: **「8.0発表効果で増収。費用先行計上で利益横ばい」**
- Phase 5 §4-2 が記録した会社説明 `[Company]`: **「8.0 の費用先行計上」**

**加えて文書内で自己矛盾していた**: P6/§6-1 は「費用先行の兆候はない」、§6-2 と §11-4 は「**FY2027.3 は費用先行年**」と書いていた。

**正しい整理**:

| 位相 | 該当期 | 利益率 |
|------|-------|-------|
| **発売前年度**（FY2024.3、7.0の前年度） | Q1〜Q4 | 40.0 / 38.0 / 46.8 / 39.2% |
| **発売同一年度・発売前** | FY2025.3 Q1 | 52.8% |
| **発売四半期** | FY2025.3 Q2 | **32.7%** |
| **発売同一年度・発売後** | FY2025.3 Q3/Q4 | 36.2 / 40.0% |
| 平常期 | FY2026.3 Q1〜Q3 | 37.5 / 40.8 / 39.0% |
| **直近** | FY2026.3 Q4 / **FY2027.3 Q1** | 30.2% / **28.3%** |

> **【v0.2の結論】前サイクルでは、費用は「発売**前年度**」ではなく「**発売四半期以降**」に現れた**（FY2025.3 Q2 の 32.7%）。日本基準ではソフトウェア開発費は資産計上→発売後償却が通常であり、これと整合する。
> **v0.1 の「n=1 の FY2027.3 Q1 を根拠に仮説を棄却する」は、同じ n=1 の FY2025.3 Q2 を棄却材料から外しており非対称だった。**
> **仮説は否定されていない。ただし現れる時期が「前年度」ではなく「発売四半期以降」である可能性が高い。**

**なお FY2026.3 Q4 の 30.2% は頑健でない**: 累計値の差分算出（rev 410−304、op 151−119）であり、累計が億円丸めなら **29.0〜31.4%** の幅を持つ。**直近の下端更新を示す頑健な観測は FY2027.3 Q1（28.3%、直接値）の1点のみ。**

3. **確率加重は Phase 4 §4-3 の事前分布の重み付けと整合させること。**

## 11. Phase 7 への引き継ぎ事項

1. **弾力性は単一値で渡さない。ε = 0.72〜0.81 の幅**（一次差分〜log-log）で扱い、**契約慣性仮説が正しい場合に 3年地平で ε が 1.0 に漸近しうる**ことを悲観側に置く。§4-4 の表を使う。
2. **Phase 4 のキャラ数予測は条件付きである。** 「ρ一定」「ρ と I は負に結合」「経路ではなく終点のみ意味を持つ」を必ず併記する。
3. **利益は名目売上 × 名目マージンで計算する。** CC売上に名目マージンを掛けてはならない。
4. **マージンバンド: Bear 26〜31%（0.25）/ Base 31〜38%（0.50）/ Bull 38〜45%（0.25）。** アンカーは通期4年＋四半期13期しかなく、**FY2023.3 の 54.6% は外れ値**。
5. **8.0 のパッケージ・パルスは +40.1億を発売四半期に1回**（`params.PULSE_LAUNCH_Q`）。**【第15次で訂正】+42.2億（中央値 +38.4億）は足切り混在版の値**。v0.1 の +22.1億 でもない。
6. **8.0 の発売は FY2027.3 Q4。費用は発売四半期以降に本格化する見込み**（§6-1）。FY2028.3 が発売翌年。予測地平（2029年）は発売の2年後。
7. **3タイトルの内訳は渡さない。** 合計のみ。DQX+FFXI の構成比は 10〜17% の幅。
8. **係数ドリフトを不確実性に算入する**（R10）。悲観シナリオ（キャラ約555k）は**観測レンジ外の外挿**であり、その領域の観測は紅蓮初期（2017-2018年）に集中している。
9. **地域別の非対称性**（JP が粘り OCE が急減、2026年の反発は海外主導）は、**新規/復帰/継続の地域別内訳が存在しないため動態モデルには組み込めない。** 感度分析の定性的材料として扱う。
10. **外生ショック2件**: DQX キッズタイム終了（2026-06-25、増収方向）、FF14モバイル中国版終了（2026-09-30、K4b 減）。**いずれも金額は不明。**
