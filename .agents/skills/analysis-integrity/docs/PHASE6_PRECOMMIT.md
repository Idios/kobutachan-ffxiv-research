# Phase 6 着手前コミットメント（過剰適合の防止）

**確定日時**: 2026-08-26、**モデル構築に着手する前**に記載。以後、事後に緩めない。

## 1. 許容誤差（Phase 0 の暫定 ±15% を採用）
- **バックテストの対象**: MMOサブセグメントの**年次売上合計**（`[Fact]`、恒常為替）
- **合格基準**: 予測年次売上が実績の **±15% 以内**
- **四半期**: ±25% 以内（季節性・パッケージ集中のため年次より緩い）
- **分離推定の出力（K4a/K4b の内訳）は教師データにしない。** 検証はあくまで合計に対して行う

## 2. 事前に決めた不合格時の対応
- 不合格でも**係数を合うまで調整しない**
- 不合格なら「分離不能」と結論し、Phase 7 には**合計のみ**を渡す

## 3. ホールドアウト
- スクエニが個別数値・定性コメントを出した期を**アンカー**として使う。
  具体的には: AR2014（3タイトル合計約100万）、2019/6/21 株主総会「70万人超」
- これらは**係数のフィッティングに使わず**、事後の照合のみに使う

## 4. 事前に宣言する既知の限界
- MMO営業利益率の実績は通期4年＋四半期13期しかなく、マージンバンドのアンカーは薄い
- 恒常為替は売上にのみ適用。**営業利益は海外費用で部分的に自然ヘッジされるため、円安期の名目マージンはFX中立ではない**
- 地域構成比の根拠は 2017-12 の1時点のみ（JP69%/NA55%/EU51%）
