# FFXIV 事業・人口の3年予測（2026 → 2029）

Final Fantasy XIV の事業規模とプレイヤー人口を、公開データだけから3年先まで予測した分析の全記録である。
**結論そのものより、「どの前提が結論を動かすか」と「何が起きたら予測を取り下げるか」を残すことを目的にしている。**

- **予測期間**: 2026年下期 〜 2029年12月（FY2027.3 〜 FY2030.3）
- **基準日**: 2026年8月30日
- **検証**: 敵対的査読を15ラウンド。致命的58件・要修正170件・軽微135件を摘出して反映

---

## 結論（要約）

| | 予測 |
|---|---|
| **サービス継続** | 3年以内の終了は見当たらない。権利・開発・運営・課金がすべて社内に閉じており、終了事例に共通する経路（外部移管・ライセンス満了・技術基盤の保守不能）のいずれにも当たらない |
| **活動キャラクター数** | 8.x サイクル平均は 7.x 比 **−7% 〜 −21%（中心 −13%）**。走査箱を最も広く取れば下端は −23% |
| **MMO 部門の恒常為替売上** | FY2030.3 で **353億円**（確率加重、上方バイアス補正後） |
| **MMO 部門の営業利益** | **124〜151億円**（直近実績 151億円） |
| **コンテンツ供給** | すでに 4.x 比 −20%。**減ったのは頻度**（パッチ間隔 +23%）で、1パッチあたりの量は −2% |

**主指標は点推定では出していない。** 第13次の検証で、この量が観測データから識別されていないことが確定したため、結論を帯に変更した。経緯は [`docs/phase8-verification.md`](docs/phase8-verification.md) §4f–§4h にある。

## 再現方法

**依存パッケージは無い。** すべて Python 3 の標準ライブラリだけで動く（図表の生成のみ `cairosvg` を使うが、SVG は生成済みなので不要）。

```bash
# 正典パラメータを表示
python3 scripts/params.py

# 予測エンジン
python3 scripts/phase7_forecast.py

# バックキャスト検証（完了した 7.x 周期にモデルを当てて答え合わせ）
python3 scripts/phase7_backcast.py

# 全成果物の機械的な横断チェック（これが本リポジトリの中核）
./verify.sh
```

**すべてリポジトリのルートから実行する。**

### 整合チェッカ（`scripts/phase8_consistency.py`）

このリポジトリで最も重要なスクリプトである。16の文書と27のスクリプトを突き合わせ、次を機械的に検査する。

| 検査 | 内容 |
|---|---|
| A | 全スクリプトが実行できるか |
| B | 文書中の正典パラメータが `params.py` と一致するか |
| C〜F | 文書間の数値の食い違い、使用禁止値の誤用、版数の相互参照、節参照の実在 |
| G | 主要な結論数値がスクリプト出力に含まれるか。**万表記の滞留検出**を含む |
| I | **撤回済みの主張が、撤回の文脈なしに残っていないか** |
| J | **検査器の自己テスト**（既知の誤りを注入して検出できるか） |
| M/N/O | 各レポートの数値をセル単位で照合 |
| P | **構造ガードの動作確認**（下記） |

**期待される出力は `致命 0 / 要修正 0`** である。`要確認` は監査記録が旧値を引用している箇所で、これは正常。

### 構造ガード

15ラウンドで繰り返し再発した2つの誤りを、**検出ではなく「起こせなくする」**形で塞いである。

```python

# 基準が揃っていない国勢調査の比較は例外になる

# → ScaleMismatch: raw_total どうしの比較は窓長も足切りも揃っていない

# 正しい比較（窓長64日換算・足切り Lv80超統一）
P.compare_census('2024-08-27', '2026-07-20')
# → (1278805.0, 853595.0, -0.3325, '窓長64日換算・足切りLv80超統一')
```

## 方法論について

この分析の方法論上の要点は4つある。詳細は [`docs/phase8-verification.md`](docs/phase8-verification.md) §5 にある。

1. **窓長の正規化** — 国勢調査の間隔は 35〜123日とばらつく。間隔が長い回ほど多くのキャラクターを拾うので、**全観測を64日相当に換算しないと時点比較が成立しない**
2. **足切りレジームの統一** — 集計対象のレベル下限が分析期間中に3回引き上げられている。直接測れたのは最後の1段だけで、残り2段は仮定である
3. **恒常為替への変換** — 円安が売上の下落幅を 9.7ポイント覆い隠していた
4. **バックキャスト検証** — 完了した 7.x 周期に同じモデルを当てて答え合わせをすると、周期平均を **+5.0%** 上振れさせる。この分を補正している

### 査読プロセス

敵対的査読を15ラウンド行った。**致命的誤りの件数は 3 → 4 → 6 → 2 → 7 → 7 → 4 → 1 → 1 → 3 → 4 → 2 → 3 → 6 → 5 と推移し、収束していない。**

一貫したパターンは「**前のラウンドの訂正が、次のラウンドの誤りを生む**」ことだった。第15次では、**手を入れていない文書だけを対象にした「静止ラウンド」**を実施し、5件の致命的誤りを検出した。原因は「静止した文書に新しい誤りが生えた」のではなく、**下流の正典が更新されたのに上流がそれを受け取っていなかった**ことである。

**したがってこの分析は「検証し尽くした結果」ではなく「15ラウンド目で打ち切った途中経過」である。**

## データの出所と再配布について

**本リポジトリの `data/` には第三者が作成・公開したデータが含まれる。** 二次利用・再配布にあたっては各出所の条件を確認すること。

| データ | 出所 | 備考 |
|---|---|---|
| **活動キャラクター数（国勢調査）** | 幸運番長氏のブログおよび Google スプレッドシート<br>https://luckybancho.ldblog.jp/ | **有志による集計。** 全58回の記事とワールド別データ（49時点 × 85ワールド）。取得方法は [`data/census_world/SOURCE.txt`](data/census_world/SOURCE.txt) に記録 |
| 財務データ | スクウェア・エニックス・ホールディングス 有価証券報告書・決算短信・決算説明会資料 | 公開された法定開示資料 |
| 為替レート | 月次 TTM レート | |
| Steam 同時接続数 | Steam Charts | |
| 他社 MMO の財務 | NCSOFT・Krafton ほかの公開決算 | |
| サービス終了事例 | 各社の公式告知および報道 | 出所は [`data/external/case_ledger.csv`](data/external/case_ledger.csv) の `source_grade` 列と各文書の参考文献節 |

> **とくに国勢調査データは個人が長年にわたって収集・公開しているものである。** 公開リポジトリでの再配布にあたっては、**作成者への確認を取ることを推奨する。** 確認が取れない場合は `data/census_*.csv` と `data/census_world/` を除外し、README に取得手順のみを記載する形も検討されたい。
