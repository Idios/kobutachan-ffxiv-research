## 表示文

ページに出す短い言い方。「値」を言い換えただけで、事実を足さない（数は値にあるものだけ）。値が変わると検査で止まるので、そのときは表示文を見直して `python frontline/tools/ledger.py set-display <ID> <表示文>` で書き直す。

| ID | 表示 | 元の値 |
|---|---|---|
| NAA-OVOO-RECIPIENT | 契約した部隊だけに、契約の間ずっと入る | 契約を完了したプレイヤーの部隊だけに、契約状態の間ずっと加算される |
| NAA-CLAIM-MULTI | 人数で速くならない | 人数を増やしても契約は速くならない |
| NAA-NOREPEAT | 同じ地点には続けて出ない | 直前に契約が終わった地点には、続けて出ない |
| NAA-SPAWN-REFILL | 契約が終わると、別の地点が予告になる | 契約が終わって待機に戻ると、別の地点の待機中の土地が予告状態になる |
| NAA-CLAIM-INTERRUPT | 契約の実行中に攻撃を受けると中断 | 契約の実行中に敵から攻撃を受けると中断される |
| NAA-CLAIM-LOCK | 契約した土地は、終わるまで奪われない | 契約済みの土地は奪い返せない（契約が終わるまでその部隊のもの） |
| NAA-TIME-TREND | 時間が経つほど上限が減り、高ランクが出やすい | 時間が経つほど同時上限は減り、高ランクで起動しやすくなる |
| NAA-STATE-WARN | 上空の記号が完成すると契約できる | 予告中は上空に記号が出て少しずつ形になり、完成した時点で有効になる（記号が有効までの残り時間を示す） |
| NAA-CLAIM-LOOK | 契約した土地の柱に、部隊の紋章入りの旗が立つ | 柱に、部隊の紋章入りの旗が掲げられる（公式ガイドの画像は黒渦団の紋章の旗） |

## 検証役が指摘した漏れ（未対応）

- 時間切れ（残り0:00）のときの勝敗（オンサル）: ページは残り時間を軸にするので、0:00で何が起きるかが要る。オンサルのガイド、5.15ノート（基本ルールはシールロックと同様と書く）、シールロックのガイド、フロントラインの総合ページのどれにも記載がない。公式に書かれているのは7.4ノートの演習戦だけ。NAA-GOAL の備考で欠落には触れているが、行がない。一方で共通台帳の COM-MATCH-WIN の備考は、7.4の演習戦の規則を全ルールに広げて書いており、台帳どうしで食い違っている。（候補: 外部: inuism（6.18。20分終了時に最も点の高い部隊の勝ちという趣旨）と game8 本文（時間経過後は戦略値の順で順位決定という趣旨）の2系統。公式の変更記録はない。ゲーム内: 時間切れになった試合の結果画面で確認。）（**対応済み 2026-10-29**: 行 COM-MATCH-TIMEOUT・確認 IG-COM-01）
- 有効状態の土地は契約されるまで残る（時間で待機に戻らない）: 誰も契約しない有効状態の土地が自然に消えるかどうかは、ページで判断に使う規則。ガイドの『必ずこの順で移行』（有効から待機へ戻る経路がない）から読み取れるが、明示はされていない。（候補: OF-GUIDE-NAADAM（状態の順序からの推論）。外部の傍証: Edda（膠着すると、どの部隊も契約できないまま数分続く例）、FL王M（戦闘で取得が間延びする）。ゲーム内: 争奪中の土地が有効のまま何分残るかを録画で見る。）（**対応済み 2026-10-29**: 確認 IG-NAA-10・値の行は作らない（理由は reports/20261027_1/ledger-build/round2））
- 契約状態の土地の見た目（契約した部隊の旗が立つ）: 公式ガイドの契約状態の画像では、柱に契約した部隊（黒渦団）の旗が掲げられている。ページの視覚的な手がかり・アイコン素材になる公式情報だが、行がない（マップの紋章は NAA-WARN-MAPGAUGE に未確認で入っているだけ）。（候補: OF-GUIDE-NAADAM の契約状態の画像 https://lds-img.finalfantasyxiv.com/h/5/SwgpsY1Kvo7YJwgE1vB2oBUHeM.jpg）（**対応済み 2026-10-29**: 行 NAA-CLAIM-LOOK）
- 予告が始まったときの画面通知の有無: 予告→有効の時刻はゲームの表示に任せる方針なので、予告の開始を画面で知らせるかどうかは設計に影響する。ララメモ（2019）は、予告がお知らせメッセージで出ると書く（1系統・古い）。（候補: EX-LALA-518。ゲーム内: 予告開始時の画面中央の表示やログを確認する。）（**対応済み 2026-10-29**: 行 NAA-WARN-NOTICE・確認 IG-NAA-11）
